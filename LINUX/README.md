# What is Linux?
## Linux is develop by Linus Torvalds in 1997 for an free, open-source version from Unix, or what he used at the time Minux.
it often known as GNU/Linux because it use the GUN framework and license and it stand for ***GUN Not Unix***
## Who *"owns"* Linux?
No SINGLE PERSON OR ENTITY "owns" the entirety of the **LINUX SOURCE CODE**—
while Linux Torvalds owns the registered trademark for the word **Linux** worldwide to hand the daily administration of the brand,
and the **Linux Foundation** acts as his exclusive licensee. Instead, the kernel relies on a **DISTRIBUTED COPYRIGHT OWNERSHIP STRUCTURE**. 
When a developer or a corporation like IBM submits a piece of code to the kernel, they retain the copyright for their specific work. 
As a result of this Linus Torvalds owns the copyright for the code that he personally writes, and hold the copyright for the **COLLECTIVE WORK**
THE CURATED ASSEMBLY OF THE KERNEL AS A WHOLE,
But he doesn't own the individual files and lines of code written by the thousand of other contributors.

In Linux there are different types of distributions or *Distro* for short. Here are the example of each distro
- Enterprise Distro: This is for enterprise business
- Community Distro: This personal use and can be user friendly.
