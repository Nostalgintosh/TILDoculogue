# IBM / z/OS / COBOL&JCL
### KNOW IBM'S PROGRAMMING LANGUAGE AND COMPILER.

I am learning the architecture of IBM Mainframes and the programing language (COBOL AND JCL) and how the world runs on these system

Jobs **Job Control Language** is a "launching batch jobs on IBM mainframe computers. JCL code determines which programs to run, and with which files and devices for input and output. Parameters in the JCL can also provide accounting information for tracking the resources used by a job and can set which machine the job should run on."
