# Printer into the Computer Node
Turning the printer as one of the nodes for a **homelab** can help with connecting make it easier to print with a permeant IP Address and harding up this network for no one can randomly brake in your printer.

You will have to connect a printer to a laptop *Recommended: a Mac* to start the installing and harding of the printer. One connect go to the ip address in your browser. **IT IS NORMAL TO HAVE YOUR WEB-BROWSER FLAG AS UNSAFE--JUST CLICK ADVANCE AND COUNTUE** One started you need to use your pin provided by the printer. Go to the Wireless (802.xx), Wireless Setup Wizard find your preferred network and press **OK**.
